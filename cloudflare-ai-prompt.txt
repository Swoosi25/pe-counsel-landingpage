## The Worker code (src/index.js, abbreviated but faithful)
- Handles OPTIONS preflight -> 204 with CORS headers (Access-Control-Allow-Origin only when Origin is in ALLOWED_ORIGINS; methods POST, OPTIONS; headers Content-Type).
- POST / -> parses JSON, validates email regex /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/, returns 400 on bad email, {"ok":true,"dropped":"honeypot"} if the honeypot field `website` is filled.
- Appends raw signup to SHEETS_RAW webhook; if that fails returns {"ok":false,"error":"storage failed"} with 502. If SHEETS_RAW_WEBAPP_URL or SHEETS_RAW_TOKEN is missing it SKIPS the write (returns ok) and proceeds.
- Generates token, writes KV keys "v:<token>" (JSON meta, 72h TTL) and "x:<token>" ("exp", TTL+6h).
- Sends the verification email via smtp.js (raw SMTP over TLS 465/STARTTLS to smtp.strato.de using AUTH LOGIN with SMTP_USER + SMTP_PASS). If mail fails -> {"ok":false,"error":"mail failed"} with 502.
- Returns {"ok":true} only if sheets append AND email both succeeded.
- GET /verify?token=... shows name+company form; POST /complete saves the verified record to SHEETS_VERIFIED webhook and deletes the tokens.

### smtp.js (the mail sender)
Uses `cloudflare:sockets` connect() with secureTransport "starttls" to host:port (smtp.strato.de:465), reads replies expecting 220/250/334/235/354 in order: EHLO -> AUTH LOGIN -> base64(user) -> base64(password) -> MAIL FROM -> RCPT TO -> DATA -> message -> QUIT. Any wrong reply code throws and the Worker returns 502 "mail failed".
